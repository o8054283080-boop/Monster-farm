スキン

初期技

SSRスキンを所持していれば選べます(装備している必要はありません)。冒険開始時、初期デッキの看板技が入れ替わります。

専用技セット

一部のSSRスキンには専用の技セットがあります。使うと、そのモンスターの決まったカードが冒険を通してすべて専用の技に入れ替わります(報酬やショップで手に入るぶんも含みます)。冒険を始めるときに決まり、途中では変わりません。

カード演出モーション

カードを使ったときの演出です。場面ごとに設定できます。ランダムを選ぶと、所持しているものから毎回抽選されます。モーションはガチャのSR枠で手に入ります。

オーラを選択

戦闘中、キャラの周りに出るエフェクトです。全モンスター共通の設定です。

📖 遊び方

🎮 基本ルール

ブリーダーとしてモンスターを育て、60階のダンジョンを踏破するカードゲームです。各フロアでルートを選択し、敵を倒しながら強くなっていきます。

⚔️ 戦闘

ターン制のカードバトルです。手札からカードを使ってガッツ（コスト）を消費し、攻撃・防御・回復などを行います。ターン終了後に敵が行動します。ライフが0になるとゲームオーバーです。

🃏 カードの見かた・操作

  • 左上の六角形が消費ガッツ、右上がレア度
  • 中央の色と漢字で役割が分かります：赤＝攻撃 / 青＝防御 / 紫＝特殊
  • カードの地の色は種族ごとに違います
  • タップで使用、敵にドラッグでも使用できます
  • 長押ししてそのまま離すとカードの詳しい説明が出ます

📊 ステータス

  • ❤️ ライフ：0になるとゲームオーバー
  • ⚡ ガッツ：カードを使うコスト。毎ターン回復
  • 🛡️ ブロック：ダメージを肩代わりする防御値
  • ⚔️ 力：攻撃カードのダメージに加算
  • 🔰 丈夫さ：敵から受けるダメージを固定値で軽減

🗺️ ルート説明

  • 🥊 通常敵：敵と戦闘。勝つとカード報酬
  • 💀 強敵：強い敵と戦闘。カード＋遺物報酬。稀に金色のレアモンスターが出現！
  • 👹 ボス：各節目の強力なボス。倒すとスコアボーナス
  • 🍖 休息所：ライフ50%回復 or デッキ整理
  • 🏕️ 休憩所：ライフ35%即時回復。選択肢なしでそのまま次へ
  • 🥋 修行：カード強化 or 能力向上（力・丈夫さ・ライフ）
  • 🎁 宝箱：遺物を3択から1つ入手（稀にレア）
  • ❓ イベント：様々なランダムイベント。レア枠では特別な出来事も
  • 💰 行商人：ゴールドを使ってカードや遺物を購入
  • 🧪 怪しい実験場：カード合成（スコア50,000またはゴールド500）や怪しい薬に挑戦。危険だが見返りも大きい

💎 遺物

戦闘外でも効果を発揮する特殊アイテムです。強敵撃破・宝箱・イベントで入手できます。組み合わせて強力なビルドを作りましょう。

⚒️ カード合成（怪しい実験場）

カード2枚を素材に新しいカードを生成します。

  • ✨ 大成功：LRランクの合成専用カードをランダム入手
  • ⬆️ 成功：1ランク上のカードを3択
  • 💨 失敗：同ランクのカードをランダム入手

大成功確率は素材のランクによって変わります

🏆 スコア・難易度

与えたダメージ・ボス撃破・フロア到達などでスコアが加算されます。難易度が高いほど最終スコアに倍率がかかります。

  • ノーマル：スコア等倍
  • ハード：敵の攻撃1.12倍 / HP1.05倍 / スコア1.2倍
  • エキスパート：敵の攻撃1.2倍 / HP1.1倍 / スコア1.5倍
  • ベリーハード：敵の攻撃1.28倍 / HP1.15倍 / スコア1.75倍 / 65階までのレジェンドボスラッシュ解放
  • レジェンド：敵の攻撃1.4倍 / HP1.4倍 / スコア2.25倍。初期デッキに取り除けない「呪い」が入り、ボスラッシュの必殺技で受けるケガが「大ケガ」（手札に残したままターンを終えると自傷）になります

※ボスだけは別の倍率です（エキスパート以上でHP1.2〜1.5倍・攻撃1.25〜1.5倍）。

🏯 継承ショップ

冒険が終わると、到達階数と難易度に応じて継承ポイントが貯まります。負けても貯まります。タイトル画面のショップで永続強化を買えます。

  • 開始ライフ・チカラ・丈夫さ・ガッツ・初期ゴールドの底上げ
  • 取得ゴールドやレアカード・レア遺物の出現率アップ
  • 初期遺物解放：冒険開始時に候補3つから遺物を1つ持ち込めます
  • 初期手札+1：戦闘開始時の手札が1枚増えます
  • 不屈：1回の冒険につき1度だけ、ライフ0でも復活します

💎 ダイヤとガチャ

ダイヤはログインボーナス・挑戦回数・階層到達などで貯まります。ガチャでは見た目を変えるものが手に入ります（強さには影響しません）。

  • スキン：モンスターの見た目が変わります
  • アクセサリ：帽子・仮面などを最大4つまで同時装備できます
  • オーラ：戦闘中、キャラの周りに特別なエフェクトが出ます
  • モーション：カードを使ったときの演出が変わります
  • 提供割合はガチャ画面の「📊 提供割合を見る」から確認できます

🎨 カスタム装備

タイトル画面から、ガチャで手に入れたものを設定できます。

  • アクセサリは色・角度・大きさ・位置を自由に調整できます
  • 初期技：SSRスキンを持っていれば（装備しなくても）初期デッキの看板技を専用技に変えられます
  • モーション：場面ごとに設定でき、「ランダム」を選ぶと毎回変わります

🎖️ 称号

タイトル画面の「称号・挑戦回数」から、通算の挑戦回数と次の報酬までの残り、種族×難易度ごとの初踏破称号を確認できます。60階に到達すると称号とダイヤが手に入ります。
